# 🧗 boulder-coach

Внутренний веб-инструмент скалодрома (боулдеринг) для учёта посещений через
QR-код: тренер сканирует QR спортсмена и отмечает приход; ведутся календарь
посещений, абонементы, справочная сумма к оплате и статистика. Фаза 2 — трассы
и статистика по грейдам (фото — опционально, «на память»).

## Технологический стек
- **Фронтенд:** Vite + React + TypeScript + Tailwind CSS + shadcn/ui, PWA (`vite-plugin-pwa`).
- **Бэкенд/BaaS:** Supabase — PostgreSQL + Auth (e-mail/пароль + Google OAuth) + Storage + RLS + RPC.
- **Хостинг:** Cloudflare Pages (`*.pages.dev`, бесплатно).
- **QR:** генерация — `qrcode`; сканирование — `@zxing/browser` (камера через `getUserMedia`, HTTPS).
- Только русский язык (v1). Адаптив: телефон + десктоп.

## Быстрый старт
1. Выполните шаги из [`docs/MANUAL_ACTIONS.md`](./docs/MANUAL_ACTIONS.md) (Supabase, миграции, OAuth, первый админ).
2. Фронтенд (после скаффолдинга на этапе реализации):
   ```bash
   cd frontend
   cp .env.example .env        # впишите VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY
   npm install
   npm run dev
   ```

## Роли
- **Администратор** — создаёт тренеров, управляет ролями и настройками, видит всё.
- **Тренер** — заводится админом; сканирует QR, ведёт визиты/абонементы своих спортсменов.
- **Спортсмен** — саморегистрация; свой QR, календарь, статистика, остаток абонемента.

## Ключевые правила (кратко)
- Связь тренер↔спортсмен возникает при первом скане; мягкое удаление замораживает данные (история сохраняется).
- Абонемент — счётчик на пару (тренер, спортсмен); на нуле визит всё равно засчитывается.
- Одна активная сессия на пару; авто-завершение через 2 часа; завершение идемпотентно.
- Сумма к оплате = неоплаченные разовые визиты × цена тренера (по каждому тренеру отдельно).

Полные правила и edge-cases — в [`SPEC.md`](./SPEC.md).
